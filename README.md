# Jumpstart Atlas

Explore every Foundations Jumpstart (J25) theme, track the packs in your collection, and pair two halves into a play deck.

Live site: https://hugooliveirad.github.io/jumpstart-atlas/

The app is a single standalone HTML file. Collection data stays in your browser (`localStorage`). Card images and extra details load from [Scryfall](https://scryfall.com/) and [mtg.wtf](https://mtg.wtf/).
